A schema-driven REST API for tabletop RPGs. A system becomes a profile; a profile becomes a character sheet at runtime. Dice engine included.

Explore the API → Read the docs View on GitHub ↗

Schema in. Sheet out.

Each game system is only a profile. Pick one and the sheet rebuilds from its schema, with no backend code per game.

ProfilePOST /api/v1/profiles/


    

  

  
Profile trimmed to 2 of its 8 sections; the rest keep their defaults. The sheet is resolved in your browser with the same merge rules as GET /api/v1/profiles/{system_id}/sheet/. Paranormal Order is the profile shipped in the repo; D&D 5e and Ashen Road are illustrative.

What it does, endpoint by endpoint.

  
Taken from the live OpenAPI schema. Each row opens the interactive docs.

  

    GET/api/v1/profiles/blank_profile/Start from an empty profile template.public
    POST/api/v1/profiles/Define a game system as a profile.bearer token
    GET/api/v1/profiles/{system_id}/sheet/Generate a character sheet from that profile.optional auth
    POST/api/v1/dice/rolls/base/Roll XdY with kh, kl and ! operators.public
    GET/api/v1/profiles/List official profiles, plus your own when signed in.optional auth
    POST/api/v1/auth/jwt/create/Sign in and receive access and refresh tokens.public
  






  

    
    
  

  

    
    
      
  • Dynamic schemas
    Shape each system's sheet with added_fields, field_overrides and custom_schema.
    • 
      
  • Dice engine
    XdY notation, kh, kl and ! operators, modifiers, critical and fumble flags.
    • 
      
  • JWT authentication
    Registration, login, token refresh and password reset through djoser and simplejwt.
    • 
      
  • Official and private profiles
    Staff publish official systems for everyone. Every other profile stays private to its owner.
    • 
      
  • Interactive docs
    OpenAPI 3.0 with Swagger UI and Redoc, with a JWT Authorize button for protected routes.
    • 
      
  • Tested
    Unit and integration tests with pytest and factory-boy, aiming for 85%+ coverage.
    •
